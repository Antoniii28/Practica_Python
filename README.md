# Práctica de Python: Minería de Texto

Cuaderno preparado para ejecutar en **Google Colab**. Incluye limpieza del corpus, tokenización, conteo de tokens y vocabulario, eliminación de stopwords, frecuencias de términos, gráfica y retos opcionales con NLTK y stemming.

## Abrir en Google Colab

[**Abrir el cuaderno en Google Colab**](https://colab.research.google.com/github/Antoniii28/Practica_Python/blob/main/Mineria_de_Texto_Google_Colab.ipynb)

También puedes abrirlo desde Colab con **Archivo → Abrir cuaderno → GitHub** y pegar la URL de este repositorio.

## Contenido

1. Preparación del corpus de comentarios.
2. Limpieza con expresiones regulares.
3. Tokenización y métricas básicas.
4. Filtrado con el conjunto de stopwords indicado en la práctica.
5. Frecuencias globales y por comentario.
6. Gráfica de términos frecuentes.
7. Validaciones mediante aserciones.
8. Retos opcionales con NLTK y Snowball Stemmer.

## Ejecución

En Google Colab, abre el cuaderno y selecciona **Entorno de ejecución → Ejecutar todas**. Las secciones opcionales de NLTK pueden requerir descargar recursos la primera vez.
